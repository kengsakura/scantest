# ScanTest: ระบบตรวจกระดาษคำตอบด้วยกล้องมือถือ

เว็บแอปสำหรับสร้างกระดาษคำตอบ พิมพ์ แล้วใช้กล้องมือถือสแกนตรวจให้คะแนน ใช้ภายในโรงเรียน

## สิ่งที่ทำได้ตอนนี้

**ผู้ดูแลระบบ (เมนู จัดการระบบ)**
- **ห้องเรียน & นักเรียน:** นำเข้าจากไฟล์ Excel/CSV (เลขที่ · เลขประจำตัว · คำนำหน้า · ชื่อ · นามสกุล · ชั้น · ห้อง) อ่านได้ทั้ง .xlsx, CSV แบบ UTF-8 และ CSV ภาษาไทยที่ Excel บันทึก (Windows-874) ระบบสร้างห้องให้เอง แก้ข้อมูล ย้ายห้อง หรือนำนักเรียนออกได้
- **ภาคเรียน & เลื่อนชั้น:** ข้อมูลแยกตามเทอม เปิดเทอมถัดไปได้แบบคัดลอกห้องเดิม หรือขึ้นปีการศึกษาใหม่แบบเลื่อนชั้น (ห้องเดิมขึ้นชั้นถัดไป ชั้นสูงสุดจบการศึกษา แก้ห้องปลายทางได้ก่อนยืนยัน) จึงเพิ่มนักเรียนครั้งเดียว และย้อนดูเทอมเก่าได้จากตัวเลือกภาคเรียนบนแถบด้านบน
- **ครู & ผู้ใช้:** สร้างบัญชีพร้อมชื่อผู้ใช้/รหัสผ่านให้ครูเอง นำเข้าจากไฟล์ ตั้งรหัสผ่านใหม่ ปิดใช้งาน หรือลบได้
- **แบบกระดาษคำตอบ:** สร้างพรีเซตไว้ (จำนวนข้อ ตัวเลือก รูปแบบ ฝนรหัส/เขียนชื่อ คะแนนต่อข้อ) เรียงลำดับได้
- **ตั้งค่าโรงเรียน:** ชื่อโรงเรียน ข้อความหัวกระดาษ โลโก้ และจำนวนหลักของเลขประจำตัว

**ครู**
- **สร้างข้อสอบ:** เลือกพรีเซต หรือกำหนดเอง (10–100 ข้อหรือมากกว่า 2–6 ตัวเลือก ก ข ค ง / A B C D / 1 2 3 4 / ถูก-ผิด) ระบบจัดให้พอดี A4 หน้าเดียวอัตโนมัติ
- **ใส่เฉลยและคะแนน:** ตั้งคะแนนต่อข้อ ทำเครื่องหมายข้อฟรี หรือพิมพ์เฉลยเร็ว `กขคง...` บันทึกอัตโนมัติ
- **พิมพ์กระดาษ:** แบบว่าง หรือแบบแยกรายคนที่พิมพ์ชื่อและฝนรหัสไว้ให้
- **สแกน:** เปิดกล้องแล้วระบบบันทึกเอง ขึ้นชื่อกับคะแนนทันที สแกนได้แม้เน็ตหลุด (ส่งขึ้นเซิร์ฟเวอร์เมื่อออนไลน์) ฝนเกิน 1 คำตอบถือว่าผิด
- **ภาพชื่อที่นักเรียนเขียน** เก็บไว้กับทุกแผ่น (~3 KB) ใช้จับคู่นักเรียนเองได้ภายหลัง
- **ตรวจรายแผ่น:** วงเขียว/แดงบนกระดาษที่วาดจากข้อมูล ตารางรายข้อ แก้คำตอบ เปลี่ยนนักเรียน
- **วิเคราะห์ข้อสอบ:** % ตอบถูก กราฟตัวเลือก ค่าอำนาจจำแนก (r) และ KR-20
- **ส่งออกคะแนน:** แบบง่าย (คะแนนรายข้อ) หรือเต็มรูปแบบ (เฉลย / คำตอบ / ถูกผิด / คะแนน) แปลงคะแนนเต็มได้ คัดลอกคะแนนรวมเรียงตามเลขที่ไปวางที่อื่นได้ และดาวน์โหลดเป็น Excel (.xlsx) ภาษาไทย

## ตั้งค่า Supabase (ทำครั้งเดียว)

1. ใน Supabase ไปที่ **SQL Editor → New query** วางเนื้อหาไฟล์ `supabase/schema.sql` แล้วกด **Run** (เมื่อไฟล์นี้มีการอัปเดต ให้รันซ้ำได้เลย ข้อมูลเดิมไม่หาย)
2. **Authentication → Sign In / Providers → Email** ปิด **Confirm email** (แนะนำ เพราะครูที่สมัครใหม่ต้องรอแอดมินอนุมัติอยู่แล้ว และอีเมลจากระบบฟรีของ Supabase ส่งได้ไม่กี่ฉบับต่อชั่วโมง)
3. **Authentication → URL Configuration** ตั้ง Site URL เป็นที่อยู่เว็บจริง (เช่น `https://scantest-taupe.vercel.app`)
4. **บัญชีแรกที่สมัครจะเป็นผู้ดูแลระบบอัตโนมัติ** คนต่อๆ ไปต้องให้ผู้ดูแลระบบอนุมัติ หรือเพิ่มอีเมลไว้ล่วงหน้าที่หน้า ผู้ใช้ & ตั้งค่า

ค่าเชื่อมต่ออยู่ในไฟล์ `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY` เป็น publishable key ที่เปิดเผยได้) ถ้าลบสองค่านี้ทิ้ง แอปจะกลับไปเป็นโหมดทดลองที่เก็บข้อมูลในเบราว์เซอร์

## เริ่มใช้งาน (สำหรับนักพัฒนา)

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm test         # ทดสอบตัวจัดวางกระดาษ ตัวอ่าน และการให้คะแนน
npm run build    # สร้างไฟล์สำหรับ deploy (โฟลเดอร์ dist/)
```

กล้องบนมือถือต้องเปิดเว็บผ่าน **https** (เช่น deploy บน Vercel) ส่วน `localhost` บนคอมพิวเตอร์ใช้ได้เลย

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/omr/layout.ts` | คำนวณตำแหน่งทุกอย่างบนกระดาษ (หน่วย มม.) ใช้ร่วมกันทั้งตอนวาดกระดาษและตอนสแกน |
| `src/omr/config.ts` | รูปแบบกระดาษ และข้อมูลที่เก็บใน QR |
| `src/omr/scanner.ts` | ตัวอ่านกระดาษ: หาสี่เหลี่ยม 4 มุม → แก้มุมเอียง → อ่าน QR → วัดความเข้มในวงกลม (JS ล้วน ไม่ใช้ OpenCV) |
| `src/omr/grading.ts` | กฎการให้คะแนน |
| `src/scan/` | ส่วนกล้อง + Web Worker สำหรับประมวลผลภาพ |
| `src/data/store.ts` | ที่เก็บข้อมูลที่หน้าเว็บใช้ (Supabase หรือโหมดทดลองในเบราว์เซอร์) + คิวส่งผลสแกน + เทอม/เลื่อนชั้น |
| `src/lib/xlsx.ts` | อ่าน/เขียนไฟล์ Excel และ CSV (ขนาดเล็ก ไม่ใช้ไลบรารีใหญ่) |
| `src/lib/importers.ts` | จับคอลัมน์ไฟล์นำเข้านักเรียน/ครู |
| `src/lib/scoreExport.ts` | ตารางคะแนนสำหรับส่งออก |
| `src/lib/terms.ts` | ภาคเรียน การเรียงห้อง การเลื่อนชั้น ชื่อ-คำนำหน้า |
| `src/data/cloud.ts` | เชื่อมต่อ Supabase |
| `supabase/schema.sql` | ตาราง สิทธิ์ (Row Level Security) ฟังก์ชันสร้างบัญชีครู และสคริปต์อัปเกรดจากเวอร์ชันเก่า |
| `src/pages/` | หน้าต่างๆ ของเว็บ |

> **ข้อควรระวัง:** ถ้าแก้ค่าคงที่ใน `layout.ts` กระดาษที่พิมพ์ไปแล้วจะสแกนไม่ได้ ต้องเพิ่มเวอร์ชันใน QR (`OMR1` → `OMR2`) และรองรับทั้งสองเวอร์ชัน

## ขั้นต่อไป

1. แชร์ข้อสอบให้ครูคนอื่นช่วยสแกน
2. ทดสอบกับกระดาษจริง มือถือหลายรุ่น และสภาพแสงในห้องเรียน
