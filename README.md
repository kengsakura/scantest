# ScanTest: ระบบตรวจกระดาษคำตอบด้วยกล้องมือถือ

เว็บแอปสำหรับสร้างกระดาษคำตอบ พิมพ์ แล้วใช้กล้องมือถือสแกนตรวจให้คะแนน ใช้ภายในโรงเรียน

## สิ่งที่ทำได้ตอนนี้

- **ล็อกอินแยกตามผู้ใช้** มีสิทธิ์ 2 ระดับคือผู้ดูแลระบบและครู (ตอนนี้เป็นโหมดทดลองแบบเลือกผู้ใช้)
- **ผู้ดูแลระบบ** เพิ่มห้องเรียน วางรายชื่อนักเรียนจาก Excel (เลขที่ | รหัส | ชื่อ-สกุล) เพิ่มครู และตั้งจำนวนหลักของรหัสนักเรียน
- **ครูสร้างข้อสอบ** ใส่ชื่อ เลือกห้อง เลือกจำนวนข้อ (10–100 หรือกำหนดเอง) จำนวนตัวเลือก (2–6) และรูปแบบตัวเลือก (ก ข ค ง / A B C D / 1 2 3 4 / ถูก-ผิด) ระบบจัดให้พอดีกระดาษ A4 หน้าเดียวอัตโนมัติ
- **ใส่เฉลยและคะแนน** ตั้งคะแนนต่อข้อแบบรวดเดียวหรือแยกรายข้อได้ ติ๊กข้อฟรีได้ และมีช่องพิมพ์เฉลยเร็ว เช่น `กขคง...`
- **พิมพ์กระดาษคำตอบ** ได้ทั้งแบบว่าง และแบบแยกรายคนที่พิมพ์ชื่อพร้อมฝนรหัสนักเรียนไว้ให้แล้ว
- **สแกน** เปิดกล้องแล้ววางกระดาษ ระบบอ่านและบันทึกเอง แล้วแสดงชื่อกับคะแนนทันที จากนั้นสแกนแผ่นถัดไปได้เลย และมีปุ่มถ่ายรูปหรือเลือกรูปสำรองไว้
- **กฎการตรวจ** ฝนเกิน 1 คำตอบถือว่าผิด ไม่ฝนได้ 0 คะแนน ข้อฟรีได้คะแนนเสมอ ถ้าแก้เฉลยภายหลัง คะแนนทุกคนจะคิดใหม่อัตโนมัติ
- **กันข้อสอบปนกัน** กระดาษทุกแผ่นมี QR บอกรหัสข้อสอบ ถ้าสแกนกระดาษผิดชุด ระบบจะแจ้งเตือนและไม่บันทึก
- **ผลสอบ** ดูคะแนนรายคน ค่าเฉลี่ย ค่าสูงสุดและต่ำสุด ดูคำตอบรายข้อ และส่งออกเป็น CSV เปิดใน Excel ได้

## เริ่มใช้งาน (สำหรับนักพัฒนา)

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm test         # ทดสอบตัวจัดวางกระดาษ ตัวอ่าน และการให้คะแนน
npm run build    # สร้างไฟล์สำหรับ deploy (โฟลเดอร์ dist/)
```

กล้องบนมือถือต้องเปิดเว็บผ่าน **https** (เช่น deploy บน Vercel) ส่วน `localhost` บนคอมพิวเตอร์ใช้ได้เลย

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/omr/layout.ts` | คำนวณตำแหน่งทุกอย่างบนกระดาษ (หน่วย มม.) ใช้ร่วมกันทั้งตอนวาดกระดาษและตอนสแกน |
| `src/omr/config.ts` | รูปแบบกระดาษ และข้อมูลที่เก็บใน QR |
| `src/omr/scanner.ts` | ตัวอ่านกระดาษ: หาสี่เหลี่ยม 4 มุม → แก้มุมเอียง → อ่าน QR → วัดความเข้มในวงกลม (JS ล้วน ไม่ใช้ OpenCV) |
| `src/omr/grading.ts` | กฎการให้คะแนน |
| `src/scan/` | ส่วนกล้อง + Web Worker สำหรับประมวลผลภาพ |
| `src/data/store.ts` | ที่เก็บข้อมูล (ตอนนี้อยู่ในเบราว์เซอร์ จะเปลี่ยนเป็น Supabase) |
| `src/pages/` | หน้าต่างๆ ของเว็บ |

> **ข้อควรระวัง:** ถ้าแก้ค่าคงที่ใน `layout.ts` กระดาษที่พิมพ์ไปแล้วจะสแกนไม่ได้ ต้องเพิ่มเวอร์ชันใน QR (`OMR1` → `OMR2`) และรองรับทั้งสองเวอร์ชัน

## ขั้นต่อไป

1. เชื่อม Supabase: ล็อกอินด้วย Google, ฐานข้อมูลกลาง, สิทธิ์แบบ Row Level Security
2. Export ตามแม่แบบที่โรงเรียนกำหนด
3. บันทึกผลสแกนในเครื่องขณะออฟไลน์แล้ว sync ขึ้นเซิร์ฟเวอร์ภายหลัง
4. ทดสอบกับกระดาษจริง มือถือหลายรุ่น และสภาพแสงในห้องเรียน
